# Bharathi Anna — Birthday Tribute ✦

A cinematic, responsive birthday tribute website made as a personal gift for Bharathi Anna.

## Run locally

Open `index.html` in a browser. The site is a standalone HTML/CSS/JavaScript experience and requires no build step. Google Fonts are loaded from Google Fonts; the page still falls back to system fonts if unavailable.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.

Once the GitHub Pages deployment finishes, the site will be available at `https://aaron-samuel05.github.io/BharathiAnnaBirthday/`.

## Personalization notes

- The timeline uses general descriptions based on public professional themes and intentionally avoids unverified dates or personal claims.
- Replace or supplement the copy with specific memories and photos you have permission to use for a more personal tribute.
- Verify the official project links before sharing publicly.
